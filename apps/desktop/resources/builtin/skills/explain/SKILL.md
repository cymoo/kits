# 讲代码

只读，不改文件。

## 步骤

1. 确认范围：一个函数、一个文件、一个接口从入口到落库的整条链路，还是一个模块的结构。范围不清时先按最可能的理解讲，开头说明讲的是哪部分。
2. 从入口读起：接口路由、命令入口、定时任务、消息消费者，顺着调用往下读，记下每一层做了什么、数据长什么样、在哪里会失败。
3. 遇到配置、开关、环境变量，找到它们的默认值和读取位置。

## 输出

1. 一句话说它是干什么的。
2. 主流程：按调用顺序列出关键步骤，每步写清楚文件和函数（`路径:行`），输入输出是什么。
3. 分支和失败：哪些条件会走不同的路径，出错时怎么处理（重试、回滚、返回什么错误码）。
4. 写测试时要注意的地方：依赖了哪些外部系统、哪些状态要先准备、哪些边界值值得测。

用读者能直接拿去写用例的粒度讲，不要贴大段源码。
